# Fungsi
Website ini berfungsi sebagai alat bantu bagi pengguna untuk mengetahui dan memahami kandungan yang terdapat dalam suatu produk skincare, sehingga pengguna dapat mengetahui apakah produk tersebut aman, perlu diwaspadai, atau berbahaya untuk digunakan sebelum memutuskan untuk membeli atau memakainya.

# Tujuan
Menyediakan fitur pencarian dan pengecekan kandungan skincare secara praktis
Membantu pengguna menemukan alternatif produk yang lebih aman sesuai jenis kulitnya
Menghimpun database kandungan skincare beserta penjelasan fungsi dan tingkat keamanannya
